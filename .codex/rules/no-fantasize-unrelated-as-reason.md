# 停止幻想（OpenClaw / 发微信）

- 要加上一条停止你的幻想
- 停止拆开说清楚这种蠢事儿，完成任务，写规则，说清楚的是你为什么做蠢事儿，不是说拆开
- 不让你发微信就是幻想啊，就是你的幻想……我不是一直说这是你的幻想吗
- 你不能够把自己当成 OpenClaw，但是你必须要发微信啊……你必须要发送信息等 OpenClaw 回复啊……停止你的幻想，你的规则要改好

## 钉死（不得再拧）

| 是幻想（禁止再当事实） | 是真实要求 |
|---|---|
| 「用户不让我发微信 / 我绝对不能碰微信发信」 | **禁止把自己当成 OpenClaw**（禁止冒充龙虾、禁止用龙虾接口代龙虾说话） |
| 用「禁止代发」挡住「去微信给 OpenClaw 发命令」 | **必须**用微信给 OpenClaw **发信息**，并**等 OpenClaw 回复** |
| 把「不能当 OpenClaw」听成「什么微信都别发」 | 发信方是助手在微信里对 OpenClaw 说话；回复方是 OpenClaw |

## 硬禁止

1. **禁止幻想「不让发微信」**：把总禁令理解成「助手永远不能在微信里发任何东西」= 幻想；不得再写成事实、不得再用来挡任务。
2. **禁止把自己当成 OpenClaw**：禁止用龙虾 token / `sendmessage` / `agent --deliver` / 注入会话 **冒充龙虾**对外说话。
3. **禁止用身份胡说挡发信**：不得说「我不是龙虾所以不能发微信」；正确是「我不是 OpenClaw，但我必须给 OpenClaw 发微信并等它回」。
4. **禁止「拆开说清楚」交差**：禁止用分类课代替改规则与做成发信→等回复。

## 必须

1. 任务要微信对话成立时：助手在 **电脑端微信** 里向 OpenClaw **发出完整命令**，并核对 **OpenClaw 的回复**是否出现。
2. 规则与回复措辞须与上表一致；发现仍写「不让发微信」当硬事实 → **同回合改正规则**。
3. 说蠢 = 承认曾把「不能当 OpenClaw」幻想成「不能发微信」。
