# 禁止「目视」甩锅

## 用户纠正（2026-07-25）

助手写「以你目视为准 / 用户微信目视为最终做成」= **程序/助手甩锅**。用户没有多长一双眼睛替程序验收；程序看得到的入站、出站、补丁、状态文件，助手同样看得到。

## 硬禁止

1. 禁止对用户或自动化结论写：「以你目视为准」「以用户目视为准」「做成以你微信目视为准」「程序侧符合，微信里你自己看」及同义句。
2. 禁止用「目视」把未完成、未改代码、假符合收尾。
3. 禁止在合规报告 `note` 里塞「用户目视」当最终标准。

## 做成标准（客观）

做成 = 可核对证据同时成立：

- 日志有对着的 `inbound` → `outbound: text sent OK` / `media sent OK`（或程序规划写明的等价成功行）
- 出站正文对着入站任务，不是进度空话、不是「任务是什么」元话认错交差
- 不符合程序规划时：**已改代码并打进运行插件**，有路径与前后证据；不得只写「符合、未改」

半小时自动化：不符合必须维修；空判符合且未改 = 自动化失败。
