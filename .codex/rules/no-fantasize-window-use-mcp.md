# 禁止幻想窗口 · 桌面用 MCP · 不影响用户

## 用户纠正（2026-07-29）— 仅用户原话

- **mcp**
- **不影响我**
- **停止幻想**
- **别幻想窗口**
- **写进规则**

## 硬禁止

1. **禁止幻想窗口**：不知道当前屏幕上到底是哪个窗口时，禁止当作已经对准目标窗。禁止凭旧 handle、旧标题、印象、上一次脚本输出，假装「就是这个窗」。
2. **禁止幻想窗口内容**：截到直播、别的 Cursor 窗、Marketplace、空白、错误窗时，禁止当成目标对话窗已操作成功。
3. **禁止影响用户**：禁止关用户正在用的窗、禁止乱 Reload、禁止 Alt+F4、禁止抢焦点乱点、禁止为了「修对话」把用户当前工作打断。用户说「不影响我」= 操作不得打扰其正在使用的界面。
4. **禁止用坐标脚本冒充 MCP**：未用 MCP 先证实控件/窗口存在时，禁止靠百分比点击、双击猜侧栏、盲发键盘交差。

## 必须

1. 桌面 GUI 探测与操作走 **MCP**（`user-uiautomation` / `user-uia-pattern` 等），先找窗、读树、确认 Name / 进程 / 句柄对得上，再操作。
2. 目标窗未用 MCP 对上之前：只能写「还没对上窗口」，继续查；不得写「已在某某窗发了消息」。
3. 截图验收：截图对象必须是 MCP/工具刚确认的那一窗；截到无关内容 = 操作失败，不是成功。
4. 修 `state.vscdb` / 脚本可以在后台做；**不得**为修库去关用户 Cursor 窗或强迫 Reload，除非用户当场明确允许。
