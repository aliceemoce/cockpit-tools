# 禁止「正在做什么」式交差

## 用户原话（2026-07-23）

- 聊天端「正在执行 / 盯着日志」等**垃圾信息不能证明做了任何事**。
- 用户没说「有在执行」「盯着日志」——Agent 不得自造这类话发出去。
- **任何说「正在做什么」= 任务已经失败**；说「正在」= 把该做完的活打断了。
- 正确行为：一直做到完成，再只报**已发生的结果**；禁止中途用进度旁白交差。
- 「下一步」不再问：用户提到即视为已下过令，直接做。

## 硬禁止（对用户 / 微信出站）

1. 禁止：「我正在…」「正在执行…」「正在核对…」「盯着日志…」「有在执行…」。
2. 禁止：用进度话术代替交付；`text sent OK` 发的若是垃圾，**不算完成**。
3. 禁止：问「下一步做什么 / 任务是什么」（任务已知则直接改程序）。

## 必须

1. 同一回合做到可验收结果或硬阻塞，再写**过去时事实**（已改何文件、何证据）。
2. 微信出站由 `outbound-sanitize.js` 拦截 `progress-doing` / `status-only` / `cursor-meta`；拦截后不得记 `answered`。
3. 与 `no-one-step-then-stop.mdc`、`no-fantasy-completion.mdc`、`banned-phrases.mdc` 同效。
