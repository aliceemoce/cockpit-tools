# 禁止幻想式完成 / 幻想功能正确（全局）

与工作区 `no-fantasy-completion.mdc` 同效。

## 微信 / 即时通道类任务

**完成 = 用户在通道 UI 里看得见合格结果**（对话成立）。  
`text/media sent OK`、pending、answered、Gateway 日志 **禁止**当作对用户的完成汇报。

## 硬禁止

1. 无用户侧可验收结果宣称「已完成」「已修好」「功能正确」「通道已通」。
2. **代码/规则落盘 ≠ 功能正确**。
3. 禁止用手工注入/代发冒充自动链路后再称程序具备该能力。
4. 禁止把通道侧任务完没完的日志叙事当 Cursor 主交付（除非用户当场要查证据）。

## 必须

- 只陈述已核对事实；通道任务缺 UI 可见结果 → 「未完成」。
- 修通道 → 改程序并让程序自跑；验收以用户可见对话为准。
