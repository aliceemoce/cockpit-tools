# 禁止折中与半成品

## 禁止

- **折中**：能做完却砍需求、降级方案、留「以后再说」
- **Demo / POC / 样例当交付**：演示能跑 ≠ 功能完成
- **半途而废**：做一半就停、主路径没通就收尾
- **最小实现凑合**：勉强能用、先交差、缺日志缺错误处理缺验收
- **静默缩 scope**：少做了却不标明哪些项未完成
- **分步骤交差话术**：用「下一刀」「下一步再做」「分步骤」把未完成项推到口头上的后续回合

## 必须

- 按用户要求的**完整范围**做到可验收
- 编译 / 运行 / 自动化通过后再标完成
- 真卡住：只报硬阻塞点，**不把半成品当交付**

## Agent

- 不得用「先做个简单版」「最小可行」「后续再补」代替完整实现
- 多步任务逐项对照；未达条件的标 **未完成**，继续做到验收或硬阻塞
